# Focus Board

Vanilla JavaScriptで作成した、教材用のタスク管理ブラウザアプリです。

JavaScriptだけでも実用的なUIを作成できることを確認した後、機能追加に伴って状態管理、DOM操作、イベント処理の関係が複雑になる過程を観察するために利用します。

## 起動方法

```bash
pnpm install
pnpm dev
```

ターミナルに表示されたURLをブラウザで開きます。

本番用ファイルは次のコマンドで作成できます。

```bash
pnpm build
```

## 実装している機能

- タスクの追加、編集、削除
- 完了状態の切り替え
- 優先度と期限の設定
- キーワード検索
- 状態と優先度による絞り込み
- 作成日、期限、優先度による並び替え
- 完了済みタスクの一括削除
- 進捗と件数の表示
- localStorageへの保存
- デモデータのリセット

## 観察するポイント

- アプリ全体の状態をどこで管理しているか
- 状態が変化したとき、どのDOMを更新しているか
- UI、状態、イベント処理がどのように依存しているか
- 機能追加によって変更箇所がどの程度増えるか
- Reactへ移行した場合、どの処理がState、Props、コンポーネントへ対応するか
